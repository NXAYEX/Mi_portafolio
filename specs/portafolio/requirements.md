2. Hay una página de inicio y una ficha por proyecto (BuBox, OJO ON, XAI) con problema, aporte, proceso, resultado y evidencia.
3. Cada habilidad enlaza a un proyecto que la demuestra.
4. Sección Sobre mí con carrera, institución, fechas y voluntariados (Technovation Girls 2023, NiñasPro 2025).
5. Contacto con correo, LinkedIn, GitHub y descarga del CV.
6. Se lee bien en 375, 768 y 1280 px; imágenes con texto alternativo en español.
7. Todo abre sin iniciar sesión.
8. No se publican datos privados (RUT, fecha de nacimiento, dirección, teléfono).
9. Sin base de datos ni login: el contenido vive en `src/data/`.
